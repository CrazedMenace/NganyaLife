# 🚍 NganyaLife

> The ultimate Kenyan matatu driving simulator.

---

## Vision

NganyaLife is an open-world driving simulator inspired by Kenya's vibrant matatu culture. Build your fleet, customize iconic nganyas, transport passengers, grow your business, and experience Nairobi like never before.
